# KolAman

האחראית לקבלת התרעות ממספר מקורות, עיבודן, סיווגן והעברת לגורמי
הפיקוד הרלוונטיים בזמן .אמת

---

## דרישות עיקריות


- מעקב אחרי הקבצים
- שליחת התראות חדשות באמצעות Kafka
- קבלת ההתראות החדשות, ביצוע וולידציה
- בדיקת כפיליות ע״י REDIS
-

## החלטות תכנון


**NotificationGate:**

- הרכיב נבנה ב c#, בפקרוייקט worker, כיון שזה שירות שרץ ברקע ללא הפסקה,
בנוסף ה Dependent injection יותר נוחה בצורה הזאת
-  בשביל קוד נקי והפרדת אחריות יצרתי תקיית '_Service_' שהיא מספקת ל worker את השירותים שהוא צריך
- גם את FileSystemWatcher רציתי להוציא לשירות נפרד אבל כיון שלא הצלחתי להוציא נתונים מתוך הפונקציה OnCreated, עשיתי אותו בתוך ה worker
- ב FileSystemWatcher עקבתי אחרי שינוי ב "*.ready" ולא "*.json" כדיי לוודאות שכתיבת הקובץ הסתיימה
- לאחר שנוצר "*.ready" העברתי את הנתיב ל FileGetAlert, שם יצרתי נתיב ל json, קראתי אותו, עשיתי וולידציה של הדיסרליזציה והחזרתי את האובייקט
- לאחר מכן ה Worker קרא ל KafkaService, ופרסם את הדיווח


**redis_service:**

- בחרתי בטווח ב ttl של 3600 שניות (1 שעה) כיון שנראה לי שבתוך הטווח הזה זה כנראה דיווח כפול על אותה התראה

**database**
החלטתי לבחור ב mysql, כיון שאז אני יכול לאחסן את כל המידע בטבלה אחת, וכל ההתראות מגיעות במבנה אחיד וככה גם יהיה אפשר להריץ שאליתות מדוייקות ולקבל סטיטיקות מועילות
